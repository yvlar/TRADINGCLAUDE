# Lollapalooza Effects

Concept Munger : quand **plusieurs biais cognitifs s'alignent dans la même direction**, leur effet combiné est **exponentiel** (multiplicateur 5-10×) plutôt que linéaire (additif).

## Définition

Un lollapalooza apparaît quand 3-5 biais convergent simultanément sur la même décision. L'effet :
- Renforcement mutuel (chaque biais valide les autres)
- Difficulté de défense (l'investisseur ne voit pas les biais individuels)
- Comportement collectif extrême (panique ou euphorie de masse)

## Exemples historiques

### Bulle dot-com (1999-2000)

**Biais alignés** :
1. **Social proof** : tout le monde achète
2. **Envy** : "mon voisin a fait x10 sur Yahoo"
3. **Reciprocity** : analystes IB recommandent "buy" pour les clients de banque
4. **Authority** : gourous (Henry Blodget) endossent les valorisations
5. **Reason-respecting** : "internet change tout" (raison plausible)
6. **Availability** : succès récents (Amazon, Yahoo) remplissent l'attention
7. **Twaddle** : "eyeballs", "viral marketing", "burn rate" remplacent les fondamentaux

**Effet lollapalooza** : multiples 100×, voire ∞ (entreprises sans revenus). Crash subséquent -78 % NASDAQ 2000-2002.

### Bulle Real Estate (2003-2007)

**Biais alignés** :
1. **Social proof** : "tout le monde flippe des maisons"
2. **Authority** : Greenspan dit "no national housing decline"
3. **Reciprocity** : agents immobiliers, mortgage brokers payés à la transaction (pas au qualité)
4. **Excessive self-regard** : nouveaux riches surconfiants
5. **Availability** : succès récents partout
6. **Twaddle** : "household formation forever growing"
7. **Inconsistency-avoidance** : "I just bought, I can't be wrong"

**Effet lollapalooza** : prix maisons 2× en 5 ans, défauts < 1 % (false signal de safety). Crash subséquent -33 % moyen US, -50 %+ dans les zones bullish (Las Vegas, Phoenix, Miami).

### Cryptocurrency Mania (2021)

**Biais alignés** :
1. **Social proof** + **Envy** : Reddit, TikTok influenceurs
2. **Authority misinfluence** : Elon Musk pumps Doge, Bitcoin
3. **Twaddle** : "decentralized finance", "Web3", "metaverse"
4. **Recency** : tous les crypto récents avaient pumped
5. **Scarcity bias** : "21M Bitcoin only" (faux argument mais convaincant)
6. **Greater fool theory** : "even if it's worthless, others will pay more"

**Effet lollapalooza** : Bitcoin 70k$, Doge ×500, NFTs millions $. Crash 2022 : Bitcoin 16k$ (-77 %), Doge -90 %, majority NFT à zéro.

## Lollapalooza dans les ventes spécifiques

### Sears (years 2010-2018)

**Biais alignés faisant tenir des actionnaires** :
1. **Loss aversion** (deprival superreaction) : "Je ne veux pas vendre à perte"
2. **Authority** : Eddie Lampert avait un track record
3. **Liking** : le marketing brand séduit
4. **Reason-respecting** : "Real estate value" justifiait théoriquement
5. **Inconsistency-avoidance** : Lampert refuse d'admettre l'erreur

**Effet** : actionnaires perdent ~99 % du capital pendant que Lampert continue d'investir.

### Theranos (2014-2018)

**Biais alignés (board members + investisseurs)** :
1. **Liking** (Elizabeth Holmes charismatique)
2. **Authority** (Henry Kissinger, James Mattis sur le board)
3. **Social proof** ("smart people are in")
4. **Reciprocity** (inversement, scientifiques sceptiques étaient ostracisés)
5. **Twaddle** ("revolutionary blood test")
6. **Sunk cost** ("we've invested too much to back out")

**Effet** : 700 M$ levés sur une fraude, durée 4-5 ans avant exposition.

## Identifier les lollapalooza en cours

### Signaux d'avertissement

1. **Un secteur ou actif domine la conversation publique** (CNBC, Twitter, dîners en ville)
2. **Les valorisations divergent radicalement** des fondamentaux
3. **La narrative "this time it's different"** émerge
4. **Les sceptiques sont marginalisés** (career risk pour les analystes baissiers)
5. **Le retail flow s'amplifie** (Reddit forums, trading apps en surcharge)
6. **Levier monte** (margin debt records)
7. **IPOs / SPACs / nouvelles structures** financières émergent en masse

Si **5+ signaux** sont présents, lollapalooza probable.

### Réponse rationnelle

#### Pour soi
- **Zéro exposition** au coeur de la bulle
- **Réduction graduelle** de l'exposition adjacente (y compris bonnes entreprises sur-valorisées par sympathie)
- **Cash position** augmentée pour saisir le crash subséquent
- **Patience** : les bulles peuvent durer 1-3 ans après leur identification

#### En tant qu'observateur
- **Lire les bear cases** ostracisés (Wirecard sceptiques, Theranos doubts, dot-com critics)
- **Étudier les biais en jeu** comme cas d'école
- **Mémoire** pour le prochain cycle (les biais reviennent toujours)

## Inversion : créer un lollapalooza vertueux

Munger notait que les lollapalooza fonctionnent dans les deux sens. Au creux d'une crise :

1. **Disliking / Hating** : tout le monde déteste les actions
2. **Availability** : récit récent négatif partout
3. **Pain-avoiding denial** : refuser de regarder
4. **Social proof** inversé : vendre parce que tout le monde vend
5. **Loss aversion** : matérialiser pertes pour ne pas en subir plus

→ Lollapalooza négatif crée des **opportunités exceptionnelles** pour qui peut résister.

Mars 2009 et avril 2020 sont des exemples clairs de lollapalooza négatif. Les investisseurs qui ont acheté à ces moments ont fait fortune subséquente.

## Exercice mental

À chaque marché significativement déséquilibré (vers le haut ou le bas), dresser la liste des biais en action. Cet exercice :
- Détache émotionnellement (analyse plutôt que ressentir)
- Identifie les opportunités contraires
- Construit l'intuition pour les futurs cycles

## Outil pratique

Devant chaque opportunité ou narrative à la mode :
1. Lister les biais qui pourraient pousser le marché à cette direction
2. Compter le nombre alignés (3+ = lollapalooza probable)
3. Estimer la durée potentielle restante (rare > 3 ans après identification)
4. Décider de la position contraire si convaincant

## Limite

Tous les marchés tendus ne sont pas des lollapalooza. Différentiation :
- **Marché normalement cher** : multiples élevés mais pas extrêmes, sentiment optimiste mais pas euphorique
- **Lollapalooza** : multiples extrêmes, narrative "this time different", retail mania, tout aligné

Le second mérite une réaction contraire forte. Le premier mérite juste de la prudence et un possible cash position légèrement augmentée.
